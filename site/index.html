Structured state

Units, resources, map structure, visibility, and actions are represented directly instead of reconstructed from broadcast pixels.

Predictive world model

Learn what follows from a state and action before using the representation for planning.

Current replay pipeline

GitHub Actions continuously validates bounded high-MMR replay snapshots on current competitive maps.

Falsifiable by design

Dreamer/RSSM-style baselines, negative controls, multiple seeds, fixed budgets, and held-out evaluation come before frontier claims.
